## Features
- **SHA-256 Hashing**: Identifies identical files accurately, regardless of name.
- **Empty Folder Cleanup**: Easily prune leftover empty directories.
- **Detailed Logging**: Records everything to `deleted_log.txt` for peace of mind.

## Installation
1. Clone this repository or download the latest release
2. Run `delete_duplicates_gui.py` with Python 3.10+, or use the bundled `delete_duplicates_gui.exe`
3. Launch the GUI and pick a folder to scan

## Usage
- Select a target directory
- Configure scan options (subfolders, hash algorithm)
- Review detected duplicates
- Delete selected duplicates securely

## Requirements
- Windows
- Python 3.10+ (for running from source) or the bundled executable
