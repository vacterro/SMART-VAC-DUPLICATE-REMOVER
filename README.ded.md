# SMART VAC DUPLICATE REMOVER

**v0.0.2**

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-0.0.1-green.svg)

Windows-тулза, которая находит дубликаты файлов и выносит их в Корзину — не «удаляет навсегда», а именно в Корзину, откуда всё достаётся обратно. Сверка по SHA-256, никакой самодеятельности, всё пишется в лог.

[🤍 Закинуть автору на кофе](https://buymeacoffee.com/vacuum34)

## Версия
0.0.1

## Что умеет
- **SHA-256**: сверяет содержимое, а не имена. Файл переименовали десять раз — всё равно найдёт.
- **В Корзину, а не в пустоту**: на Windows удалённое лежит в Корзине и достаётся обратно. Там, где Корзины нет, диалог прямо говорит: удаляю НАВСЕГДА. Врать про восстановление не будет.
- **Чистка пустых папок**: выносит пустые каталоги. Саму выбранную папку не трогает — не бойся.
- **Лог**: каждое удаление в `deleted_log.txt`. Потом не придётся вспоминать.
- **По умолчанию безопасно**: хотя бы одна проверенная копия в группе остаётся всегда. Файл изменился после сканирования — не удаляется. Точка.

## Установка
1. Клонируй репозиторий
2. Запусти `python delete_duplicates_gui.py` на Python 3.10+
3. Открой окно и выбери папку

Exe в репозитории нет и не будет. Собирай сам рецептом PyInstaller ниже или
качай из релиза с тегом, когда он появится.

## Как пользоваться
- Выбери папку
- **Найти дубликаты** — сканирует рекурсивно (SHA-256)
- **Остановить поиск** — если передумал на середине
- Смотри найденное в дереве результатов
- Хочешь лог — включи галочку
- Удаляй выбранное (уходит в Корзину, достаётся обратно)
- **Удалить пустые папки** — для оставшегося мусора

## Сборка из исходников (W2-004)
Exe собирается PyInstaller из `delete_duplicates_gui.spec`:

```
pyinstaller delete_duplicates_gui.spec
```

Собирай с чистого коммита с тегом. В метаданные релиза пиши `VERSION`, SHA коммита, версию PyInstaller и SHA-256 собранного exe — иначе через полгода никто не докажет, из чего это собрано.

## Требования
- Windows
- Python 3.10+ (работает из исходников, бинарника в репозитории нет)
