# SMART VAC DUPLICATE REMOVER

**v0.0.2**

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-0.0.1-green.svg)

Windows 向けの堅実な重複ファイル検索・削除ツールです。削除したファイルはごみ箱に入るため復元でき、シンプルな画面、SHA-256 による照合、詳細なログを備えています。

[🤍 開発者を支援する](https://buymeacoffee.com/vacuum34)

## バージョン
0.0.1

## 機能
- **SHA-256 ハッシュ**: ファイル名に関係なく、同一内容のファイルを正確に判別します。
- **ごみ箱への削除**: 削除したファイルは Windows のごみ箱に移動し、復元できます。ごみ箱が存在しない OS では、確認ダイアログが「完全に削除される」ことを明示します。
- **空フォルダーの整理**: 残った空のディレクトリをまとめて削除します（選択したフォルダー自身は削除しません）。
- **詳細なログ**: すべての削除を `deleted_log.txt` に記録します。
- **既定で安全**: 各重複グループの検証済みコピーを必ず 1 つ以上残し、スキャン後に変更されたファイルは削除しません。

## インストール
1. このリポジトリをクローンします
2. Python 3.10 以上で `python delete_duplicates_gui.py` を実行します
3. 画面を開き、スキャンするフォルダーを選びます

実行ファイルはリポジトリに含まれていません。下記の PyInstaller のレシピで自分で
ビルドするか、タグ付きの GitHub リリースが公開されたらそこから入手してください。

## 使い方
- 対象のディレクトリを選択します
- **重複を検索** を押すと再帰的にスキャンします（SHA-256）
- **検索を停止** を押すと長いスキャンを中断できます
- 検出された重複を結果ツリーで確認します
- 必要に応じて削除ログを有効にします
- 選択した重複を削除します（ごみ箱に入り、復元可能です）
- **空フォルダーを削除** で空のディレクトリを整理します

## ソースからのビルド (W2-004)
Windows 実行ファイルは `delete_duplicates_gui.spec` から PyInstaller で作成します:

```
pyinstaller delete_duplicates_gui.spec
```

リリースはクリーンでタグ付きのコミットからビルドしてください。バイナリを再現・検証できるように、アプリの `VERSION`、ソースのコミット SHA、PyInstaller のバージョン、生成した exe の SHA-256 をリリース情報に記録します。

## 動作要件
- Windows
- Python 3.10 以上（ソースから実行します。リポジトリにバイナリはありません）
