# SMART VAC DUPLICATE REMOVER

**v0.0.1**

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-0.0.1-green.svg)

Надійний інструмент для Windows, який знаходить і видаляє дублікати файлів — видалене потрапляє до Корзини (можна відновити) — з чистим інтерфейсом, перевіркою за SHA-256 і докладним журналом.

[🤍 Підтримати розробника](https://buymeacoffee.com/vacuum34)

## Версія
0.0.1

## Можливості
- **Хешування SHA-256**: точно визначає однакові файли незалежно від імені.
- **Видалення до Корзини**: видалені файли потрапляють до Корзини Windows і можуть бути відновлені. На системах без Корзини діалог підтвердження прямо попереджає, що видалення безповоротне.
- **Очищення порожніх тек**: легко прибирає порожні каталоги (сама вибрана тека ніколи не видаляється).
- **Докладний журнал**: кожне видалення записується до `deleted_log.txt`.
- **Безпечно за замовчуванням**: щонайменше одна перевірена копія кожної групи дублікатів завжди зберігається; файли, змінені після сканування, ніколи не видаляються.

## Встановлення
1. Клонуйте цей репозиторій
2. Запустіть `python delete_duplicates_gui.py` через Python 3.10+
3. Відкрийте інтерфейс і виберіть теку для сканування

Виконуваний файл до репозиторію не додається. Зберіть його самостійно за
рецептом PyInstaller нижче або завантажте з позначеного релізу GitHub, коли
такий буде опубліковано.

## Використання
- Виберіть цільову теку
- Натисніть **Знайти дублікати**, щоб просканувати рекурсивно (SHA-256)
- Натисніть **Зупинити пошук**, щоб перервати тривале сканування
- Перегляньте знайдені дублікати в дереві результатів
- За бажанням увімкніть журнал видалень
- Видаліть вибрані дублікати (потрапляють до Корзини, відновлюються)
- Скористайтеся **Видалити порожні теки** для очищення порожніх каталогів

## Збірка з джерел (W2-004)
Виконуваний файл Windows збирається через PyInstaller з `delete_duplicates_gui.spec`:

```
pyinstaller delete_duplicates_gui.spec
```

Релізи слід збирати з чистого позначеного коміту. У метаданих релізу записуйте `VERSION` застосунку, SHA вихідного коміту, версії PyInstaller і SHA-256 зібраного exe, щоб бінарний файл можна було відтворити та перевірити.

## Вимоги
- Windows
- Python 3.10+ (застосунок працює з джерел; бінарного файлу в репозиторії немає)
