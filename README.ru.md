# SMART VAC DUPLICATE REMOVER

**v0.0.3**

Надёжное Windows-приложение для безопасного поиска и удаления дубликатов файлов: чистый интерфейс, проверка по SHA-256 и подробное логирование.

[🤍 Поддержать автора](https://buymeacoffee.com/vacuum34)

## Версия
0.0.1

## Возможности
- **SHA-256 хеширование**: точно находит одинаковые файлы вне зависимости от имени.
- **Удаление в корзину**: удалённые файлы попадают в корзину Windows и восстанавливаются. На системах без корзины диалог подтверждения прямо предупреждает, что удаление безвозвратно.
- **Очистка пустых папок**: легко удаляет оставшиеся пустые каталоги (сама выбранная папка не удаляется).
- **Подробное логирование**: всё записывается в `deleted_log.txt`.
- **Безопасно по умолчанию**: всегда сохраняется хотя бы одна проверенная копия каждой группы; файлы, изменившиеся после сканирования, не удаляются.

## Установка
1. Клонируйте репозиторий
2. Запустите `python delete_duplicates_gui.py` через Python 3.10+
3. Откройте GUI и выберите папку для сканирования

Исполняемый файл в репозиторий не коммитится. Соберите его сами по рецепту
PyInstaller ниже или скачайте из помеченного релиза GitHub, когда такой будет
опубликован.

## Использование
- Выберите целевую директорию
- Нажмите **Найти дубликаты**, чтобы просканировать рекурсивно (SHA-256)
- Нажмите **Остановить поиск**, чтобы прервать долгое сканирование
- Просмотрите найденные дубликаты в дереве результатов
- При желании включите логирование удалений
- Удалите выбранные дубликаты (отправляются в корзину, восстановимы)
- Используйте **Удалить пустые папки** для очистки пустых каталогов

## Сборка из исходников (W2-004)
Исполняемый файл Windows собирается через PyInstaller из `delete_duplicates_gui.spec`:

```
pyinstaller delete_duplicates_gui.spec
```

Релизы следует собирать из чистого помеченного коммита. В метаданных релиза записывайте `VERSION` приложения, SHA исходного коммита, версии PyInstaller и SHA-256 собранного exe, чтобы бинарник можно было воспроизвести и проверить.

## Требования

- Python 3.10+ (приложение работает из исходников; бинарника в репозитории нет)
